# Политика безопасности

## Как сообщить об уязвимости

Сообщай приватно через GitHub Security Advisories этого репозитория
(«Security» → «Report a vulnerability»). Пожалуйста, не открывай публичный issue
для того, что можно проэксплуатировать. Первичный ответ — в течение нескольких
дней; проект небольшой и ведётся одним человеком.

Wumpo — офлайновый десктопный прототип без сетевого кода, аккаунтов и удалённых
сервисов, поэтому реальная поверхность атаки узкая: разбор недоверенных файлов
replay и сохранений, а также цепочка поставки при сборке.

## Поддерживаемые версии

Поддерживается только вершина ветки `main`. Выпущенных версий пока нет, бэкпортов
не будет.

## Секреты

Никогда не коммить API-ключи, пароли, токены, приватные ключи, облачные и
production-учётные данные, SSH-ключи и `.env` с реальными значениями. Вместо
этого — `.env.example` с плейсхолдерами. Проекту сознательно не нужны секреты
вообще: CI работает без единого.

`.gitignore` — не механизм защиты. Он предотвращает случайное добавление файла и
ничего не делает с тем, что уже закоммичено.

### Если секрет всё же попал в репозиторий

1. Прекрати коммитить.
2. Удали его из рабочего дерева и проверь через `git diff`.
3. Если он попал в историю — считай его скомпрометированным. Публикация для
   компрометации не требуется.
4. Ротируй или отзови учётные данные. Этот шаг идёт до чистки, а не после.
5. И только потом переписывай историю, если это всё ещё имеет смысл.

## Настройки репозитория

Secret scanning и push protection включены в пределах возможностей тарифа.
Workflow объявляют `permissions: contents: read` и ничего шире, если задаче это
действительно не нужно. Сторонние GitHub Actions пинятся по SHA коммита, а не по
тегу. Проверки GitHub — подстраховка, а не основной контроль: проверяй локально
перед push.

## Зависимости

Каждая зависимость обосновывается по чеклисту из `CONTRIBUTING.md` и
записывается в `THIRD_PARTY.md` с лицензией и зафиксированной версией.

## Сознательно не реализовано

Загрузка сторонних игр на устройство потребовала бы валидации пакетов,
контрольных сумм, подписей, совместимости версий, защиты от отката, безопасного
загрузчика и режима восстановления. Ничего этого нет и ничего из этого не будет
проектироваться заранее.
