# ADR-005: Пока никакого SDK, формата пакетов и сторонних игр

## Статус

Принято

## Контекст

Долгосрочное видение включает сторонних разработчиков, пишущих игры для Wumpo, а
это подразумевает SDK, формат пакета `.wumpo` с метаданными и подписями,
загрузчик, совместимость версий и защиту от отката.

Каждое из этого — публичный контракт. Опубликовать контракт до того, как
внутренний runtime стабилизировался, означает либо сломать его потом, либо быть
им замороженным, — а runtime ещё не выпустил ни одной игры.

## Решение

Никаких SDK, портала разработчика, менеджера пакетов, магазина, системы плагинов,
публичного игрового API и скриптового языка. Игры компилируются в бинарник вместе
с runtime.

Вместо этого держим внутренние интерфейсы достаточно чистыми, чтобы они могли
стать SDK позже: граница платформы из ADR-004, жизненный цикл игры в `src/game` и
уже версионированный формат сохранений.

Вопрос об SDK открывается заново только после того, как игра будет доделана,
сыграна и доказана.

## Последствия

**Плюсы:** интерфейсы остаются изменяемыми, пока мы всё ещё выясняем, какими они
должны быть. Никаких обязательств по совместимости, никакой поверхности атаки от
загрузки чужого кода, никакой инфраструктуры распространения.

**Минусы:** добавление игры означает пересборку. Никто посторонний пока не может
собрать что-то для Wumpo.

Замечание о лицензии: репозиторий публичен под MIT, поэтому runtime уже сейчас
может быть использован кем угодно, в том числе в конкурирующем устройстве. Это
принятый и осознанный размен — открытость сейчас, а идентичность продукта держится
на железе, игре и названии, а не на эксклюзивности кода.

## Рассмотренные альтернативы

**Спроектировать формат `.wumpo` сейчас, реализовать потом.** Отклонено: формат,
спроектированный до появления реальной игры, зафиксировал бы догадки о том, что
играм нужно. Записан как будущая возможность, а не как спецификация.

**Сделать скриптовый слой (Lua), чтобы игры были данными.** Отклонено:
интерпретатор со своей кучей на чипе с килобайтами RAM ради проблемы —
стороннего контента, — которой у нас нет.
